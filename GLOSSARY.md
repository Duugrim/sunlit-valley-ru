## Стиль перевода

### Формат имён предметов в тексте

- В квестах (FTB): `&6Русское имя (English Name)&r` для важных предметов и жителей.
- В скиллах: `§6Русское имя§7`, английский в скобках — только если нужно для узнаваемости (например, Dragontooth Axe один раз).

### Оставить по-английски

- **Rippit!**, **Largoit!**, **Pressit!** — не переводить.
- **Blockchain** (навык) — как в EN.
- Коды Minecraft: `§`, `&`, `%%` (проценты в lang-файлах).

### Лексика

- «Не стакается» — допустимый игровой жаргон.
- «Фермерство» как система навыка — ок; «начать фермерство» в сюжете → **«ступить на путь земледелия»**.
- «6 утра (6 AM)» — при первом упоминании механики продажи/полива.
- «Постарайтесь», не «Старайтесь» (глава «Укрощение огня»).

### Квесты с названием = предмет

Если заголовок квеста в EN — имя предмета (Oak Resin, Pine Tar, Preserves Jar…), переводи заголовок по глоссарию.

## Частные правки (проверенные формулировки)


| Контекст            | Было / нельзя                           | Надо                                              |
| ------------------- | --------------------------------------- | ------------------------------------------------- |
| Приглашение кузнеца | каменные инструменты (Stone Tools)      | каменные инструменты — без EN-примечания          |
| Хранение денег      | случайных сундуках                      | сундуках                                          |
| Изменённые уровни   | (Gold), (Diamond) в описании прогрессии | убрать EN в скобках                               |
| За готовку          | блюда из кристаллов земли               | **станции для готовки** с Земляными кристаллами   |
| Кадка               | ставить несколько на фоне               | **сделать хотя бы несколько для работы на фоне**  |
| Подсочник           | подключить деревья к капельнику         | **к подсочнику можно подключиться** на дубе, ели… |
| Geode quest         | Яйца короля                             | **Киндер-сюрприз**                                |
| Lead ore            | назойливая, отравляющие разум           | **проблемная**, **выделяет отравляющие облака**   |
